REPRODUCIBLE BY DESIGN
What this study establishes
Comparison scope
All seven policies were compared in saved-reference replay: no cache, static threshold, VectorQ, selectivity-aware threshold, reverse threshold, extra audits and exact key. Live API runs cover P0/P2/P3 cold and P2/P3 warm.
Reference labels
64 validation and 96 held-out test reviews were sampled across eight challenge strata. Shipping, defect and sarcasm labels come from Ministral 3B, not independent human annotation. Enriched sampling does not estimate population prevalence.
Implementation fidelity
P2 is a tested reimplementation of Algorithms 1 and 2 from VectorQ arXiv v1. It is not a byte-identical copy of the official repository, which now implements vCache.
Measurement boundaries
Replay calls are simulated and timings are local. Live runs use precomputed embeddings and share network contention. Warmup costs are separate. Live P2/P3 differences cannot be attributed to an inactive threshold.
